A quarterly filing goes in. A research note comes out.

Drop in a results PDF, an exported spreadsheet or a plain text update. What comes back is a four-page note in a fixed house format — financial tables, narrative sections and charts, laid out for print.

  • ReadText and ruled tables are pulled from the document, so figures keep the rows they belong to.
  • ExtractA model fills the report schema. Anything the source doesn't state is left null, never guessed.
  • TypesetCharts are drawn, the template is filled, and headless Chromium prints it to A4.
